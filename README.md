# Safety Bracelet (Bluetooth version)

1. Upload safety_bracelet_ble.ino to the ESP32-C3 (no Wi-Fi or internet settings needed).
2. Open this folder in Android Studio, let Gradle sync, Run on your phone.
3. In the app: "Find / change bracelet" > pick it, add an emergency contact, Start monitoring.
4. Allow permissions, "Display over other apps" and full-screen alerts. Set battery to unrestricted.
